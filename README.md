# Agentic AI Customer Service Chatbot

## Overview
This project is a simple agentic AI chatbot that simulates a customer service assistant.

## Features
- Handles order status, refund policy, and product suggestions
- Uses multiple agents
- Maintains conversation memory using LangGraph

## How to Run
pip install -r requirements.txt
export OPENAI_API_KEY="your_api_key"
python app.py

## Example
User: Where is my order?
Bot: Looks like your order is still being processed.

User: Can I get a refund?
Bot: You can request a refund within 30 days.

User: What should I buy?
Bot: I’d recommend a MacBook Air or Dell XPS.
